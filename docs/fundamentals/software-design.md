# 软件设计师：计算机基础与软件质量

本文是考试复习速记；协议端口和质量模型会随标准演进，实际项目请以对应协议和标准文档为准。

## 计算机组成与体系结构

1. DMA控制方式是在**主存与外设**之间**直接**建立数据通道进行数据的交换处理。
2. 在微机系统中，BIOS/UEFI 固件保存在主板上的非易失性存储器中，现代设备通常是可擦写 Flash；考试题目常把它简称为 **ROM**。
3. CPU在执行指令的过程中，会自动修改程序计数器（PC）的值，以使其保存的总是将要执行的下一条指令的地址。
4. 程序计数器（PC）用于存放下一条指令所在的单元的地址。当执行一条指令时，处理器首先需要从PC中取出指令在内存中的地址，通过地址总线寻址获取。


## 数据的表示

1. 正数的原码、反码、补码相同；移码不是简单复制正数的原码，而是按规定的偏置量编码。
2. 负数的反码=原码除符号位外按位取反
3. 负数的补码=反码+1；移码通常在补码基础上翻转符号位（具体位宽和偏置量要以题目约定为准）。
4. 1 B = 8 bit；按二进制计量时应写作 1 KiB = 1024 B，十进制 1 kB = 1000 B。
5. bit（位）是最小的信息单位，Byte（字节）是常见的存储和寻址单位。
6. D：10进制；B：2进制；O：8进制；H：16进制


## 端口

常用协议端口号情况如下（端口号是默认约定，实际服务可能自定义）：
- POP3：TCP 110，邮件收取；POP3 over TLS 常用 TCP 995。
- SMTP：TCP 25 主要用于邮件服务器之间转发，客户端提交通常使用 TCP 587，隐式 TLS 常用 TCP 465。
- FTP：TCP 21 为控制连接，主动模式下 TCP 20 为数据连接；被动模式的数据端口由服务器协商。
- HTTP：TCP 80；HTTPS 通常使用 TCP 443。
- DHCP：UDP 67（服务器）和 UDP 68（客户端），用于自动分配 IP 地址等网络参数。
- SNMP：UDP 161 用于查询/响应，UDP 162 通常用于 Trap/Inform。
- DNS：UDP 53 常用于普通查询，TCP 53 也用于区域传送和部分大响应。


## 软件质量

ISO/IEC 9126 是旧版软件质量模型，质量特性和质量子特性如下；现行标准通常参考 ISO/IEC 25010：
功能性（适合性、准确性、互用性、依从性、安全性）
可靠性（成熟性、容错性、易恢复性）
易使用性（易理解性、易学性、易操作性）
效率（时间特性、资源特性）
可维护性（易分析性、易改变性、稳定性、易测试性）
可移植性（适应性、易安装性、一致性、易替换性）
